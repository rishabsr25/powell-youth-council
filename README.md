# Powell Youth Council

Website for the Powell Youth Council — a student governing body serving the City of Powell, Ohio, organizing events, volunteering, and advocating for the community.

## Structure

```
index.html      Main page markup
css/style.css   All styles
js/main.js      Team roster data, scroll reveal, scrollspy nav, scroll progress bar
assets/         Images/icons (empty for now)
```

## Running locally

No build step — just open `index.html` in a browser, or serve it locally:

```
npx serve .
```
